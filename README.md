# Дневник растений

Приложение для телефона и компьютера: превращает архив фото растений в дневник, где любое растение можно сравнить по годам, сезонам и клумбам.

Работает как веб-приложение с установкой на главный экран (PWA): без сервера, без аккаунтов, без интернета после первой загрузки. Фото и дневник хранятся только на устройстве.

## Возможности (версия 0.4)

- **Импорт** фото из галереи или папки (на компьютере): дата и GPS из EXIF, защита от дублей, превью и рабочая копия.
- **Разбор**: неразобранные фото сгруппированы в прогулки; пакетная отметка «Это клумба…» / «Это растение…», подсказка ближайшей клумбы по GPS, «Не растение» — удаление из приложения (повторный импорт его не вернёт), отмена последнего действия, правка даты.
- **Места деревом**: зоны → клумбы и виды (ракурсы, которые снимаются из года в год); поиск, недавние, создание прямо внутри зоны.
- **Доразметка растений**: фото, уже отмеченные клумбой, можно открыть снова и отмечать растения в несколько заходов; общие планы отмечаются видом и в доразметку не попадают.
- **Каталог**: виды → сорта → растения; места → клумбы → растения; карточки с фото по месяцам.
- **Просмотр** фото во весь экран с отметками.
- **Сезоны**: сетка «годы × сезоны / месяцы» для растения, сорта, вида или места; «весна (лето, осень, зима) по годам»; фильтр лет и столбцов; закреплённые обложки периодов.
- **Сравнение клумб**: один сорт или вид в разных клумбах по сезонам или месяцам.
- **Сравнение двух фото** рядом или шторкой.
- **Дневник**: съёмка из приложения сразу с отметкой клумбы, вида или растения; записи о событиях (цветение, подкормка, обрезка, пересадка…), быстрая запись «Зацвело сегодня».
- **Резервная копия и перенос**: весь дневник или изменения с прошлого раза в файл .zip (большие — частями до 2 ГБ); загрузка на другом устройстве со слиянием: отметки объединяются, удалённое удаляется, дублей нет; напоминание, если копии давно не было.

Дальше: подсказки по визуальному сходству.

Известное ограничение: Android при выборе фото в браузере удаляет из них координаты GPS, поэтому подсказки клумб по GPS работают при импорте на компьютере.

## Установка на телефон

Откройте адрес приложения:

- **Android (Chrome)**: меню ⋮ → «Добавить на главный экран» / «Установить приложение».
- **iPhone (Safari)**: кнопка «Поделиться» → «На экран „Домой“».

## Разработка

Без сборки и зависимостей: чистые ES-модули.

```
python3 -m http.server 8080   # открыть http://localhost:8080
npm test                       # модульные тесты (Node 20+)
```

Сквозные тесты (`tests/e2e/*.mjs`) используют Playwright и Chrome; путь к `playwright-core` и папкам с тестовыми фото передаётся через переменные `PW`, `PHOTOS`, `PHOTOS2`, `NEWPHOTO`.

При изменении файлов приложения поднимите `VERSION` в `sw.js`, иначе установленное приложение не увидит обновление.
