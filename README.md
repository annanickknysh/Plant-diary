# Дневник растений

Приложение для телефона и компьютера: превращает архив фото растений в дневник, где любое растение можно сравнить по годам, сезонам и клумбам.

Работает как веб-приложение с установкой на главный экран (PWA): без сервера, без аккаунтов, без интернета после первой загрузки. Фото и дневник хранятся только на устройстве.

## Версия 0.1 — ядро

- **Импорт** фото из галереи или папки (на компьютере): дата и GPS из EXIF, защита от дублей, превью и рабочая копия.
- **Разбор**: неразобранные фото сгруппированы в прогулки; пакетная отметка «Это клумба…» / «Это растение…», подсказка ближайшей клумбы по GPS, «Не растение», отмена последнего действия, правка даты.
- **Каталог**: виды → сорта → растения; места → клумбы → растения; карточки с фото по месяцам.
- **Просмотр** фото во весь экран с отметками.

Дальше: сетка сезонов и сравнение клумб, съёмка и записи дневника, перенос между устройствами файлом, подсказки по визуальному сходству.

## Установка на телефон

Откройте адрес приложения:

- **Android (Chrome)**: меню ⋮ → «Добавить на главный экран» / «Установить приложение».
- **iPhone (Safari)**: кнопка «Поделиться» → «На экран „Домой“».

## Разработка

Без сборки и зависимостей: чистые ES-модули.

```
python3 -m http.server 8080   # открыть http://localhost:8080
npm test                       # модульные тесты (Node 20+)
```

Сквозной тест (`tests/e2e/smoke.mjs`) использует Playwright и Chrome; путь к `playwright-core` и папке с тестовыми фото передаётся через переменные `PW` и `PHOTOS`.

При изменении файлов приложения поднимите `VERSION` в `sw.js`, иначе установленное приложение не увидит обновление.
